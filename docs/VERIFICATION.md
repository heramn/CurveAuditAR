# Release verification

Verified October 24, 2026, Central Time. The working application is publicly
deployed at **https://curveauditar.vercel.app**. Source is published at
**https://github.com/heramn/CurveAuditAR**, branch `main`.

The exact current production commit is reported by `/release.json`. Run
`npm run verify:production` to compare it with HEAD and compare deployed
geographic assets byte for byte against the local committed files.

GitHub-to-Vercel continuous deployment is connected and demonstrated: pushes
of bc3c708 and 84e8f49 generated new ready production builds without a manual
deployment. Production homepage, JS/CSS and geographic assets return HTTP 200
without authentication. The preferred hostname is in use.

- 17 core/calculation/dataset checks pass on Node 24 in GitHub Actions.
- 15 browser regression cases pass across 1440×1000 desktop, 768×1024 tablet
  and 390×844 phone viewports. Successful full run:
  https://github.com/heramn/CurveAuditAR/actions/runs/40146672478

  GeoJSON export, actual report data, print, physics input changes/validation,

  production session. This is session evidence, not perpetual monitoring.

## Issues found and repaired

- CARTO returned HTTP-success tiles carrying an API-key watermark. Switched
  to the standard OSM tile service and visually verified actual geographic
  context. Visible attribution remains; no tile scraping or offline prefetch.
- The first browser run exposed a brittle timer assertion: simulated distance
  legitimately advanced before Stop was clicked. The test now measures the
  actual paused distance and checks stability; all 15 cases passed afterward.
- Development warned against importing a public JSON file directly. Regional
  context now loads through its public URL.
- Phone screenshot review found missing labels beside unknown evidence.
  Labels now remain visible, with regression assertions for posted speed and
  banking/friction labels.

## Deployment tooling and monitoring

The Vercel connector could create the project but its team-scoped Git operation
returned 403. The existing authenticated Vercel CLI successfully linked,
deployed and connected the same intended project without new credentials.
GitHub HTTPS OAuth lacked workflow permission; an existing authorized SSH key
successfully pushed source and workflow. No new account access was granted.

Vercel Hobby runtime-log retention rejected the one-hour query. The supported
ten-minute production-error query returned zero runtime error records at
7:26 PM Central. This is a static
application without server functions; browser observations and direct asset
checks are the main runtime evidence. No telemetry, log drain or ongoing
monitoring service was installed.

## Remaining limitations and unverified behavior

No known unresolved critical defect in the exercised application paths.
Physical phone audio, actual GPS/motion hardware, OS-specific permission
dialogs, background operation and field engineering accuracy remain unverified.
Browser speech support varies and the text/manual replay fallback is provided.
No full AR-3 inventory, official speed-zone match, state-centerline comparison,
LiDAR coverage validation, banking/friction measurement, matched crash
integration, population-based county fatality rates or direction-aware GPS
alerts are implemented. Research thresholds need survey validation and
calibration before any operational safety use.
